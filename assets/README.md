# Anvil app icon

Approved by the project owner on 2026-11-04. Generated with the built-in imagegen tool; no external image API or credentials were used.

- `anvil-source.png`: original approved artwork with transparent outer margins.
- `icon.png`: 1024px application/Dock icon.
- `icon.icns`: macOS icon, 16px through 1024px.
- `icon.ico`: Windows icon with 16, 24, 32, 48, 64, 128 and 256px frames.

Regenerate the platform formats on macOS with `npm run icons:build`. This only resizes and encodes the approved image. The generated platform files are committed, so Windows builds do not need iconutil.

## Generation prompt

Design a genuinely premium, original brand mark and desktop app icon for a leading open-source AI coding agent. Start from a completely new visual concept. This is an ambitious independent software brand, not a blacksmith business. NO anvil, NO hammer, NO angle brackets, NO code symbols, NO loop arrows, NO circuitry, NO robot face, NO brain, NO letters, NO wordmark, NO stars or sparkles. Visual direction: Swiss modernist identity, monolithic but open, precise, quietly powerful. The emblem is a single sculptural geometric aperture: two strong interlocking angular planes that form an open, asymmetric diamond with a decisive diagonal opening toward the upper right. It should suggest autonomous forward motion and an open system through pure shape, without illustrating those ideas. Broad warm-white faces, a clean dark negative-space channel, unmistakable silhouette; one integrated mark with at most three large shapes. Extremely restrained, beautifully balanced optical proportions, memorable at 24px. Avoid resemblance to the OpenAI knot, Anthropic A, Google Gemini star, Cursor cube, or a generic paper plane. Matte near-black rounded-square tile with subtly softened corners, off-white emblem, absolutely no neon and no colored gradient. An exceptional software identity that feels engineered and editorial rather than gaming or futuristic stock art. The tile spans 88% of the square canvas, emblem spans about 55%, ample breathing room, centered with subtle optical correction. Truly transparent space outside the tile. Finished square desktop icon asset only, no mockup, no labels, no explanatory graphics, no watermark, no presentation board.
