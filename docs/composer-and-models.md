# 输入框、模型与附件

输入框参考简洁的双层布局：上层自适应文本框，下层左侧添加菜单和权限模式，右侧模型选择和发送/停止按钮。完全访问使用橙色盾牌；文件夹和附件有内容时才展示可移除标签。快捷键保留 Ctrl/Cmd+Enter，通过发送按钮提示，不常驻占位。

## 模型

模型弹层支持搜索、最近使用排序、添加、编辑、删除及连接测试。按对话保存选项，每条任务记录实际模型配置；运行中锁定切换。已有 SDK 会话调用 switchModel，保留消息上下文。当前适配 HTTPS Responses API；不宣称其他协议可用。不显示未实现的思考强度或麦克风。

配置在 userData/composer/models.json，仅存供应商名称、模型 ID、接口 URL、Keygrant 环境变量名称和图像能力。内置 DeepSeek 继续使用原有 BYTEPLUS_ARK_API_KEY 和 BYTEPLUS_ARK_RESPONSES_URL。密钥启动时从 Keygrant 注入，主进程提取后删除环境变量；新增密钥引用需重新启动并注入。只把当前模型凭据传给 worker，worker 提取后删除，不传给工具子进程。模型设置不接受明文密钥。

连接测试由用户点击触发，先保存配置，再向指定模型发送小额真实请求；不会自动遍历测试供应商。只有服务器返回成功才显示连接成功。

## 附件

支持原生文件选择器、多文件拖入和剪贴板图片/文件。支持 UTF-8 文本（每个最多 256 KB）以及 PNG、JPEG、GIF、WebP（每个最多 5 MB）；每条消息最多 8 个文件、总计 10 MB。PDF、Office 和其他二进制文档暂不支持。

文件在添加时复制到 userData/composer/attachments，以随机 ID 保存快照。IPC 不接受任意本地路径作为附件引用；发送时重新校验 ID、数量和大小。草稿保存附件元数据及 ID，历史任务保存附件清单，SDK 持久化实际消息内容。文本快照作为不可信附件内容加入提示，图片通过 SDK 的 data URI 附件接口传入。附件不会自动授予原目录访问权限。旧附件快照暂时保留，后续增加清理策略。

模型图像能力需用户根据供应商配置显式声明，内置 DeepSeek 默认文本。界面及主进程均拒绝向文本模型发送图片。切换供应商后的旧图片历史兼容性仍取决于供应商与 SDK。

模型选择和附件草稿按 conversation ID 存于本地界面存储，任务元数据在 SQLite。当前不实现 @文件、Git 引用、云端附件同步。

## 聊天展示与 Fork

新建入口统一为 New chat。用户消息使用右对齐蓝色气泡，助手回答左对齐，不重复显示 Anvil 名称。已结束且包含回答的任务下方提供 Fork 按钮。

Fork 在一个 SQLite 事务中复制截至该回答的任务记录，生成独立聊天，继承目录和分组，权限回到 Ask；界面沿用该回答的模型选择。复制记录不共享 SDK session ID，新聊天首次发送时将历史问答注入新的运行会话。历史附件仅包含名称，不重放正文、图片或工具进程状态；本地文件不会回滚。文本上下文超过 200,000 字符时明确报错，不静默截断。
