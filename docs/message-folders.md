# 已发送消息的目录标签

## 问题

输入框显示会话当前选择的目录，但已发送的用户消息只有文字，用户无法判断该条消息是否携带了目录。

## 方案

任务创建时复制本轮实际传入 runtime 的目录列表，保存为任务的 `folders`，随历史消息持久化。用户消息气泡内显示「已附带目录」和文件夹标签，悬停查看完整路径；标签不提供移除操作。输入框仍保留当前会话目录，用于后续轮次。

历史标签不随之后增删会话目录改变。不把文件夹为空时的内部工作目录显示为用户附件；旧记录缺少发送时目录快照时不猜测或回填。无目录消息不显示目录区域。这里表示目录已随请求传入，不表示模型已经读取了所有文件。

## 验证

回归检查：无目录、多目录、调用方数组修改、目录授权变化以及重新加载任务后，历史快照仍正确；快照与实际传给 runtime 的目录一致。类型检查与桌面构建。
