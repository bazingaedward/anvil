# 字体与外观设置

## 问题

界面大量使用固定像素字号，聊天正文偏小，用户无法按屏幕和阅读习惯调整。仅增大根字号无法覆盖固定字号、Monaco 和终端。

## 方案

- 在设置中增加「外观」，管理界面字号、聊天字号、代码字号、终端字号和聊天行高。
- 默认值依次为 15px、16px、14px、14px、1.75；字号范围依次为 13–18、14–24、12–22、12–22，行高范围为 1.4–2.2。
- 界面字号统一使用 CSS 变量并保留原有标题/辅助文字的层级；聊天正文、输入框、提问卡片独立使用聊天字号。代码块、编辑器及 diff 使用代码字号，xterm 使用终端字号。
- 修改即时生效，支持恢复默认值。偏好保存在当前应用来源的 localStorage，与账号云端同步分开；开发服务器与安装版分别保存。
- 读取时校验并修复无效值；保存失败提示用户。修改字号不重建编辑器或终端，不丢失编辑内容、选择及终端会话。

## 验证

类型检查、配置边界校验测试、构建；检查设置保存/重载/恢复默认、聊天和代码字号、编辑器/终端实时更新，以及大字号下设置窗口仍可滚动操作。
