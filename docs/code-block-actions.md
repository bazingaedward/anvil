# 代码块操作

## 问题

回答中的代码和命令块只有正文，用户必须手动选中文本才能复制。

## 方案

为 Markdown 块级代码增加固定高度的工具栏：左侧显示语言（未指定时为“文本”），右侧提供复制按钮。复制完整纯文本，保留换行和缩进，不包含语言标签或 Markdown 围栏；成功后短暂显示“已复制”，失败使用现有错误 toast。工具栏始终可见，长代码只在正文区域横向滚动。行内代码保持原样，流式更新时复制当前已显示内容。

剪贴板通过受信任主窗口的 IPC 调用 Electron `clipboard.writeText`，仅暴露文本写入，不开放剪贴板读取权限。整段回答的复制也复用这个接口，避免被浏览器权限拒绝。

## 验证

检查带语言、无语言、未闭合围栏及行内代码的渲染；验证复制内容与块内正文一致、失败反馈和成功反馈均不改变布局；运行类型检查。
