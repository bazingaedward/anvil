# 用户消息附件展示

## 问题

用户消息气泡重复展示工作目录，图片仅显示文件名，无法直接查看发送内容。

## 方案

- 普通消息、steering 和后续执行的排队消息使用同一用户消息组件：图片缩略图在文字上方，点击打开大图，支持关闭按钮和 Escape。
- 非图片附件保留文件名。图片加载失败时保留文件名及明确提示，不影响消息正文。
- 目录仅展示在会话顶部的工作区目录入口，展开可查看完整路径并选择目录；气泡不再显示目录。
- 保留会话目录授权、任务目录快照、发送给模型的附件和目录数据。
- 图片通过现有受信任且按账号隔离的 IPC 读取本地附件，验证 ID 和图片类型；不将图片正文加入任务记录或日志。

## 验证

验证图片读取的账号隔离、非法 ID、非图片拒绝；验证图片区域位于文字前，普通文件仍显示；运行类型检查，并检查已有附件和目录传递测试。
